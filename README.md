# Lety Digital Learn

Build a mobile-first educational web application called Lety Digital Academy, a product by Lety Tech Consultancy, focusing on Phase 1: the branded homepage, mobile-first navigation, learner dashboard, course outline, and progress tracking.

Key requirements from the specification:
- Brand & Purpose: Lety Digital Academy by Lety Tech Consultancy. Tagline: "Learn Digital Skills. Practice Anywhere." Designed for complete beginners in Kenya and wider African markets using smartphones with small screens and limited data. Clean, professional SaaS-style UI with large touch targets, readable typography, and generous spacing.
- Public Homepage: Hero ("Learn Computer Skills, Even Without a Computer"), primary CTA ("Start Learning") and secondary CTA ("Explore Courses"), core pillars (Learn, Practise, Build Confidence, Earn Certificates), course previews, "How it works", benefits, FAQ, and Lety Tech Consultancy footer.
- Mobile-first Navigation: Seamless mobile shell with bottom navigation bar and header for easy access to Home, Courses, Dashboard, and Profile.
- Learner Dashboard: "Welcome back" personalized header, overall learning progress, "Continue Learning" card, stats (completed lessons, exercises, quizzes, streaks), and enrolled course cards with progress percentages.
- Course Outline & Navigation: Comprehensive course catalog and module/lesson breakdown for Computer Basics, Word Processing, Spreadsheets, and Presentations, showing the learning flow (Learn → Watch → Practice → Try Alone → Quiz).
- Progress Tracking: Functional progress state that updates lesson statuses, calculates completion rates, and allows resuming courses.
